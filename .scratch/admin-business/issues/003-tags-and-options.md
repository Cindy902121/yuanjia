# Ticket 003：B2B 標籤與規格選項維護

- Status: done
- Depends on: 002
- Blocks: 005

## Goal

在商品編輯頁補上既有 B2B 標籤套用與多規格／包裝選項維護，讓詢價使用的選項和商品基本資料分開管理。

## Scope

- 只能選擇已啟用的 B2B 標籤；不提供在此頁建立新標籤。
- 標籤使用可搜尋的多選控制，空集合代表清除全部關聯。
- 規格選項使用可排序的 inline rows，包含 `option_code`、規格文字、包裝文字、啟用狀態與排序。
- `option_code` 建立後不可修改；規格選項不包含價格、庫存或供應能力。
- 空狀態、重複代碼、格式錯誤、停用選項與儲存失敗均有清楚回饋。

## Acceptance criteria

- 商品編輯頁能讀取並更新標籤關聯，不會混用 B2C 標籤。
- 可新增、編輯、停用、排序與刪除規格選項；既有 RFQ 的文字快照不被回寫。
- 鍵盤使用者能完成標籤選擇與規格列操作，不只依賴拖曳。
- 儲存中的 row 不可重複送出，失敗時保留輸入並提供重試。

## Non-goals

- CSV 匯入、圖片管理、價格欄位與 RFQ 管理頁。

## Validation

- 標籤通路隔離、選項 CRUD、排序、重複代碼、停用與 RFQ snapshot 契約測試。

## Implementation notes

- B2B 標籤 API 只讀取已啟用的 `b2b_tags`，並允許 B2B 管理員以空陣列清除關聯；B2C 標籤仍由管理員權限隔離。
- 商品編輯頁提供搜尋多選標籤、規格選項 inline rows、鍵盤上下移、代碼唯讀、停用／啟用與錯誤重試回饋。
- 規格選項 API 改由 `requireBusinessAdmin` 保護；新增、更新、重複代碼、排序、停用與 RFQ 文字快照契約已加入整合測試。`DELETE` 沿用資料模型的軟刪除語意（停用），避免破壞既有 RFQ 的外鍵參照。
