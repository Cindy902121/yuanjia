# B2B 需求篩選器：通路優先需求規格書

版本：v1.0  
日期：2026-09-02  
狀態：待實作  
適用範圍：元家 B2B 前台「需求篩選器」

## 1. 目的

讓企業客戶先以自身的**主要銷售通路**辨識需求，而非先理解魚種、加工方式或包裝規格。

使用者完成最多兩次選擇後，系統直接顯示已標記為適合該通路的 B2B 商品；商品規格、包裝、交期與合作條件仍由後續型錄與詢價流程確認。

## 2. 已確認的產品決策

- 篩選器固定採用「主要通路 → 分類 → 商品結果」結構。
- 不設第三層問題。
- 不納入「食品加工廠」與「團膳供餐」作為本版通路選項。
- `量販／超市` 不再細分；選取後直接顯示商品結果。
- `連鎖` 僅存在於 `餐飲` 之下，代表連鎖餐飲，不與連鎖零售混用。
- 商品可同時標記多個通路組合；不得因商品品類而自動推定通路適用性。
- 前台不公開價格、即時庫存、MOQ 或供應承諾。

## 4. 使用流程

```text
進入需求篩選器
  ↓
選擇「主要通路」
  ├─ 盤商／批發、電子商務、傳統零售／專賣、餐飲
  │    ↓
  │  選擇對應分類
  │    ↓
  │  顯示商品結果
  │
  └─ 量販／超市
       ↓
     直接顯示商品結果
```

### 4.1 畫面與互動規則

1. 首頁題目為：`您的主要銷售通路是？`
2. 第一層以 5 張可點擊選項卡呈現；同一時間僅可選擇一項。
3. 有分類的主要通路被選取後，第二區題目為：`您的通路分類是？`
4. 第二層同樣只能選擇一項；選取後立刻載入商品結果，無需額外「下一步」或第三層。
5. 選取 `量販／超市` 時跳過第二層，直接載入結果。
6. 結果頁顯示目前篩選路徑，例如：`電子商務 ＞ 團購`；提供 `重新選擇` 與 `清除篩選`。
7. 結果商品可前往商品詳情／選擇規格／加入詢價單；實際規格、包裝與報價以業務確認為準。

## 5. 商品配對規則

### 5.1 標籤方式

- 每一項 B2B 商品可有 0 至多個通路標籤。
- 同一商品可同時適用多種主通路與分類。例如某商品可同時標記：

  ```text
  ecommerce_group_buy
  ecommerce_marketplace
  foodservice_general
  ```

- 商品沒有通路標籤時，不應被納入任何需求篩選器推薦結果；仍可在企業型錄以其他方式被搜尋到。
- `mass_retail` 是完整葉節點標籤，不另設子分類。

### 5.2 結果比對

| 使用者選擇 | 系統查詢標籤 |
| --- | --- |
| 盤商／批發 ＞ 小盤 | `wholesale_small` |
| 電子商務 ＞ 團購 | `ecommerce_group_buy` |
| 量販／超市 | `mass_retail` |
| 傳統零售／專賣 ＞ 海鮮專賣店 | `seafood_specialty_store` |
| 餐飲 ＞ 連鎖 | `foodservice_chain` |

結果只顯示具有完全相符葉節點標籤的商品，不採用品名、魚種或既有用途欄位做自動猜測。

## 6. 結果頁內容

每項結果至少顯示：

- 商品圖片
- 商品編號與商品名稱
- 品類／品牌
- 規格、包裝、產地、保存資訊（有資料才顯示）
- `查看詳情` 與 `選擇規格`／`加入詢價單` 動作

不顯示：

- 公開價格
- 即時庫存
- 未確認的認證、交期或 MOQ

### 6.1 無結果狀態

若沒有相符商品，顯示：

> 目前尚無適合此通路的推薦商品。您可以重新選擇通路，或前往企業型錄瀏覽完整品項並提出詢價需求。

按鈕：`重新選擇`、`前往企業型錄`。

## 7. 資料與後台需求

1. 需新增或擴充商品與「通路標籤」的多對多資料關係；單一商品不可只存一個通路值。
2. 後台新增／編輯 B2B 商品時，管理者可勾選上述固定通路標籤。
3. 前台顯示名稱與系統儲存值必須分離；日後調整中文文案不得改變既有查詢結果。
4. 新增通路或分類前，須同步更新：
   - 前台篩選器選項與文案
   - 商品標籤選項
   - API 查詢白名單／驗證
   - 測試資料與驗收案例
5. 商品通路標籤的建立、補齊與維護責任由業務／商品資料管理端確認；前端不得自行推導。

## 8. 驗收條件

| 編號 | 驗收條件 |
| --- | --- |
| AC-01 | 使用者可在第一層看到且只能選擇 5 個主要通路之一。 |
| AC-02 | 除量販／超市外，使用者選取第一層後只會看到該通路的第二層分類。 |
| AC-03 | 使用者選取量販／超市後，系統不顯示第二層，直接顯示 `mass_retail` 商品結果。 |
| AC-04 | 使用者選取第二層後，系統直接顯示商品結果，沒有第三層問題。 |
| AC-05 | 電子商務 ＞ 團購只顯示標記 `ecommerce_group_buy` 的商品。 |
| AC-06 | 餐飲 ＞ 連鎖只顯示標記 `foodservice_chain` 的商品。 |
| AC-07 | 商品可同時出現在多個通路結果中，但不得因未標記而被推定出現在結果中。 |
| AC-08 | 無結果時提供重新選擇與前往企業型錄，不顯示錯誤或空白頁。 |
| AC-09 | 結果與商品頁不公開價格、即時庫存、未確認 MOQ 或交期。 |

## 9. 不在本版範圍

- 依料理菜系、魚種、加工方式、包裝或價格再詢問第三層條件。
- 自動依商品品類推論適用通路。
- 公開報價、即時庫存、線上結帳。
- 食品加工廠與團膳供餐通路。
