# 大型 B2B 型錄的搜尋介面模式研究

研究日期：2026-08-13  
目的：為元家 2,000+ 項 B2B 水產型錄，找出可降低規格型採購搜尋成本的介面模式。本文件僅採用供應商官方網站可見的介面作為事實來源；「元家建議」為依此做出的設計推論。

## 已驗證的官方模式

| 官方案例 | 官方頁面中可直接觀察到的模式 | 元家可採用的做法 |
| --- | --- | --- |
| [RS](https://uk.rs-online.com/web/) | 首頁搜尋欄可尋找關鍵字、製造商料號和 RS 料號；頁面同時提供大量主分類入口。 | 搜尋框明確承諾可找「品名、元家品號、品牌、規格／加工／包裝」，下方保留可點擊的主品類捷徑。 |
| [RS 繼電器類別結果](https://uk.rs-online.com/web/c/relays-signal-conditioning/relays/?intcmp=UK-WEB-_-HP-BS1-_-1225-_-relays) | 17,065 筆結果以 Availability、Brand、Features、Contact Configuration、Mount Type、Product Type、Maximum Load Current 等分面篩選；長選項以 `Show All` 收納。頁面亦提供相關性排序、重設與最多 8 項比較；商品列有料號、品牌和主要屬性。 | 先顯示最能縮小水產規格的 4–5 個條件：品類、品種／原料、加工方式、規格／尺寸、包裝；其餘條件放在「更多條件」。商品列固定顯示品號、產地、加工、規格、包裝，讓使用者能直接加入詢價。 |
| [Grainger](https://www.grainger.com/) | 搜尋欄提示為「keyword, item, model or part #」；首頁同時提供產品分類，並標示型錄規模為 1.5M products。 | 不用三個固定品類按鈕取代搜尋；改為一個可輸入多種識別方式的主搜尋，並將「蝦類／貝類／魚類」等做成搜尋下方的快速入口。 |
| [Grainger 安全用品類別](https://www.grainger.com/category/safety?analytics=nav) | 篩選面板包含 Previously Purchased、分店供貨狀態和可搜尋的品牌條件。 | 登入後可增加「常詢品項」捷徑（應以詢價／採購歷程命名，不宣稱庫存）；品牌或供應商數量很多時，篩選選單內應可搜尋。 |
| [Grainger Bulk Order](https://www.grainger.com/content/bulk-order) | 提供逐列輸入 Item # + Quantity，並支援貼上多筆資料。 | 第二階段提供「貼上多個元家品號」的快速加詢價單入口；MVP 可先顯示介面與逐筆確認，暫不承諾批次送出。 |
| [McMaster-Carr：Filters](https://www.mcmaster.com/products/filters/) | 模糊搜尋後先出現 `Most Likely Products`，再列 `All Results`；結果使用 System of Measurement、Thickness、Material、For Use With、Filter Type 等高密度屬性篩選，且多個篩選值清單內另有搜尋欄。 | 搜尋「蝦」時，先給「最可能符合」的品類／商品，再列全部結果；篩選值多時讓使用者可在篩選內搜尋，而不是要求捲很長的清單。 |

## 建議的搜尋區呈現

### 預設狀態

```text
🔍  搜尋品名、元家品號、品牌、規格／加工／包裝          [搜尋]
    例如：白蝦 31/40、去殼、1kg、菲律賓、YJ-XXXX

快速瀏覽： [蝦類] [貝類] [魚類] [調理食品] [刺身／生食] [查看全部品類]
```

這保留現有「蝦類／貝類／魚類」的直覺入口，但讓搜尋框成為主操作，而不是一個寬輸入框加三顆彼此地位相同的按鈕。

### 輸入時的建議清單（元家新設計）

```text
搜尋：蝦

最可能符合
  商品    冷凍白蝦 31/40｜去殼｜1kg
  商品    熟白蝦 51/60｜尾留｜500g

依品類瀏覽
  蝦類（xxx 項）

常用規格
  去殼    31/40    1kg    熟凍
```

這個群組順序採用 McMaster-Carr 的「最可能符合」概念，並將結果區分成商品、品類與規格詞；使用者不必先知道精確品名。登入者可在此區塊另外看到「常詢品項」，但只有在確有詢價歷程資料時才顯示。

### 搜尋結果的篩選與選擇

1. 預設只展示最有採購辨識力的條件：品類、品種／原料、加工、規格、包裝。
2. 點「更多條件」後才出現產地、品牌／供應商、認證、保存方式等；選項過多時，篩選清單內可再搜尋。
3. 已選條件應以可移除的標籤顯示，並提供「清除全部」。
4. 結果列顯示可比較的規格，不公開價格、即時庫存或結帳操作；主要動作維持「加入詢價單」。

## 尚未當成競品事實的功能

本次檢視的公開官方頁面，沒有找到足以可靠證實下列功能的公開介面或官方說明，因此不可描述為「Grainger、RS、McMaster-Carr 都這樣做」：

- 自動完成（autocomplete）或即時搜尋建議。
- 最近搜尋（recent searches）。
- 搜尋零結果時的人工協助／聯絡表單。

這三項仍可作為元家的產品決策：建議將「最近搜尋」限於本機未送出資料或登入者自己的歷程；零結果時提供「找不到規格？告訴我們品種、加工、尺寸、包裝」的簡短詢價協助。它們是為元家流程新增的功能，而非上述官方案例的未經證實模仿。

## 結論

元家的搜尋應由「單一多欄位語意搜尋 + 快速品類入口」開始；輸入後先協助判斷商品／品類／規格，結果頁才逐步以規格條件收斂。這比在搜尋列右側並列少數品類按鈕更適合 2,000+ 項、且買方常帶規格而非精確品名進站的 B2B 型錄。
