# 元家 B2C 首頁視覺改版提案：日系雜誌編排風

> 提案版本：v1.0｜提出日期：2026-08-19｜提出人：A（Sika）
> 狀態：**提案階段，待 B、C 確認**——目前只實作在獨立預覽路由 `/design-preview`，尚未套用到正式首頁或任何其他頁面。
> 參考網站：[貴丸 -TAKAMARU-（福岡鮮魚與仕出し店）](https://takamaru-fukuoka.com/)
> 對應現行規格：[design.md](../design.md)（v1.0，2026-08-11，團隊已確認採用中）——本文件是在此基礎上提出的**風格延伸提案**，不是要推翻現行 design.md。

---

## 1. 提案背景

現行 [design.md](../design.md) 已經確立「海洋藍＋鮮活綠」的品牌色彩系統，並套用到全站（Header、Footer、首頁、商品頁、購物車等），B 的 `/login` 也依此對齊過，是目前全站唯一、團隊已確認的設計基準。

這份提案是額外的風格方向探索：改走**日系雜誌編排感（Minimal Editorial Japanese Style）**——大量留白、襯線標題、細字重、非對稱版面、克制的色彩——參考對象是實際存在、風格明確的鮮魚／食品業者官網 [takamaru-fukuoka.com](https://takamaru-fukuoka.com/)。

**這不是要偷偷置換現行設計**，而是先做一版可以實際點開來看的首頁預覽，讓三人一起判斷方向對不對，再決定要不要、以及要套用到多大範圍。

---

## 2. 參考網站分析

分析方式：實際開啟 [takamaru-fukuoka.com](https://takamaru-fukuoka.com/)，用瀏覽器讀取真實渲染出來的 `getComputedStyle`，不是憑印象猜測。

| 項目 | 觀察結果 |
|---|---|
| 版面結構 | ABOUT → QUALITY → MENU → STORE → FAQ → CONTACT，每個區塊有「英文小標＋日文大標」的雙語 eyebrow，部分區塊有 `01`／`02` 數字編號 |
| 英文小標字體 | `"Josefin Sans"`，字重 200（極細）、`letter-spacing: 1.4px` |
| 中／日文大標字體 | 明朝體（該站用日本專用字型「秀英明朝 L」），字重可低至 100，行高約為字級的 1.8 倍，非常鬆 |
| 內文字體 | `"Noto Sans JP"`，同樣帶 `1.4px` 字距，行高約 1.8 |
| 背景色 | `rgb(234, 234, 234)`（約 `#EAEAEA`，偏冷灰的暖白） |
| 文字色 | `rgb(74, 74, 74)`（約 `#4A4A4A`，深灰非純黑） |
| 區塊留白 | 實測 QUALITY 區塊上下 `padding` 約 **126.5px**（桌面），留白份量遠超一般商業網站 |
| 動態效果 | 使用 AOS（Animate On Scroll）函式庫做捲動淡入；圖片無明顯的 hover 縮放（本提案額外加上，非參考站原有） |

**核心美學結論**：不靠色彩或裝飾製造精緻感，而是靠「留白份量」「字重對比（細標題＋更細的英文字）」「數字編號的職人感」堆疊出質感，色彩本身極度克制（幾乎只有灰階＋一個深色文字）。

## 3. 設計系統提案

### 3.1 色彩

| Token | 色碼 | 用途 | 備註 |
|---|---:|---|---|
| 背景（主） | `#FAF9F6` | 頁面主背景 | 暖白，比參考站的冷灰白更貼近使用者原始規格書要求 |
| 背景（區塊交錯） | `#F3F1EB` | 用來區隔區塊，取代目前的實線卡片框 | |
| 文字（主） | `#2B2B2B` | 標題、主要內文 | |
| 文字（次） | `#4A4A4A` | 內文、描述 | |
| 文字（輔助） | `#8A8A8A` / `#9A9A9A` | 英文小標、日期、次要資訊 | |
| 點綴色 | `#3E5C6B` | 數字編號、少量強調 | 刻意選跟現行 `brand-ocean-700`（`#005DAA`）同色系但**降低彩度**的深藍，銜接品牌識別，同時符合「質樸低彩度」的要求，不是另外選一個無關的顏色 |
| 分隔線 | `#2B2B2B` 15%／`#e5e2da` | 區塊分隔、清單分隔線 | 取代現行的 `border-subtle` 實框卡片 |

**與現行 design.md §5.2 的差異**：現行系統是「60% 白／暖白、25% 海洋藍、10% 鮮活綠、5% 珊瑚重點色」的高辨識度配色；本提案是「95%+ 中性色（白／灰／墨），色彩只出現在極少數的數字編號」的極簡配色。兩者是不同的設計策略，不建議混用同一頁面。

### 3.2 字體

| 角色 | 字體 | 字重 | 字距 | 備註 |
|---|---|---:|---:|---|
| 英文小標／數字編號 | `Josefin Sans`（Google Fonts） | 200–300 | `0.25em`–`0.35em` | 新增字體引用 |
| 中文大標題 | `Noto Serif TC`（Google Fonts，`next/font/google` 載入） | 300–400 | `0.03em`–`0.05em` | 現行 design.md §5.3 已定義為 `--font-serif`，但**目前用系統字型宣告、沒有實際載入 Web Font**，此提案改用 `next/font` 確保跨裝置都能正確顯示明朝體質感，不會因使用者系統沒裝這個字型而退回黑體 |
| 內文 | `Noto Sans TC`（Google Fonts，`next/font/google` 載入） | 300–400 | 一般 | 同上，現行也是系統字型宣告，此提案改為確定載入 |
| 內文行高 | — | — | — | `line-height: 2`（現行 design.md §5.3 內文行高為 1.75–1.8，此提案再拉寬，呼應參考站的鬆弛感） |

### 3.3 版面與間距原則

- **非對稱版面**：拒絕齊頭卡片格線，改用「文字欄＋圖片欄」不等寬的兩欄配置（例如品牌故事區塊文字欄 0.9fr／圖片欄 1fr）。
- **數字編號系統**：每個主要區塊用 `01`／`02`／`03`／`04` 標示順序，取代單純的圖示或色塊，強化「職人條列」的敘事感。
- **細線分隔取代卡片框**：企業優勢、食安控管重點等原本用 `border + 陰影` 的卡片，改成單一 `1px` 上邊框的清單列，減少視覺噪音。
- **區塊留白**：桌面版單一區塊上下 `padding` 抓 `128px`（`py-32`）～`160px`區間，明顯大於現行 design.md §5.4 建議的 `80–120px`。

### 3.4 互動與動態效果

- **圖片 Hover**：`transform: scale(1.06)`、`transition: 0.7s ease`，滑鼠移到照片上時緩慢放大，容器需 `overflow: hidden` 裁切溢出範圍。
- **捲動淡入（Scroll Reveal）**：區塊進入視窗時由下往上淡入（`opacity 0→1` + `translateY 24px→0`），用原生 `IntersectionObserver` 實作，不額外引入 AOS 這類函式庫依賴；`prefers-reduced-motion: reduce` 時直接跳過動畫、內容直接顯示（沿用全站既有的無障礙規則，design.md §7.3）。

## 5. 待 B、C 確認的問題

1. **方向是否採用**：這套「日系雜誌編排風」跟現行「海洋藍＋鮮活綠」的品牌識別策略是兩個不同方向，是否要正式取代目前的 design.md？還是維持現行方向，這份提案僅供參考？
2. **套用範圍**：如果採用，是全站套用（Header／Footer／`/login`／`/products` 系列都要跟進），還是僅限首頁？Header／Footer 是共用元件，一旦改動會直接影響 B 已經對齊過的 `/login`。
3. **時程**：目前團隊已經依照現行 design.md 完成大部分 B2C 頁面（首頁、商品瀏覽／詳情、購物車結帳、需求協助工具等），全站改版屬於較大工程，需要評估是否影響既有排程（C 8/17–8/22 的資料庫擴充排程、B 的 B2B 型錄開發）。
