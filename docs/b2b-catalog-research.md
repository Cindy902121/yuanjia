# B2B 型錄介面研究：食品／海鮮供應商

研究日期：2026-08-13。以下皆為供應商自營（第一方）網站，用於整理資訊架構與詢價流程；不移植其文案或商業承諾。

## 可參考案例

| 案例 | 觀察到的做法 | 可套用到元家 |
| --- | --- | --- |
| [Royal Seafood 產品型錄](https://royalseafoods.ca/products) | 先以「全部／蝦／鮭魚／鮪魚…」做產品類別篩選；每張產品卡顯示品名、特徵標籤、切法、包裝、產地、保存狀態與箱重，價格不公開，每張卡直接 `Request Quote`。 | 型錄首屏應採「搜尋＋類別 chips＋篩選」；卡片只保留採購判斷資料：產品名稱／產品編號、規格或包裝、產地、保存方式與食安標籤。CTA 改為「加入詢價籃」，不要放價格或即時庫存。 |
| [Ocean Fish USA 詢價流程](https://oceanfishcorp.com/) | 詢價表單採逐步相依欄位：產品 → 產品型態 → 規格／呈現方式 → 數量；可把多項商品加入「已選產品」清單，再填總備註送出。 | 商品詳情與詢價籃採兩層：先選規格／包裝與數量，再加入詢價籃；籃內可調整每品項數量、單位與備註，最後一次送出。 |

## 建議改成的元家 B2B 型錄骨架

1. **頁首**：企業型錄名稱；右側固定 `詢價籃（0）`，再加「需求協助」入口。
2. **查找列**：搜尋產品名稱／編號；下一列為產品分類；進階篩選收在「篩選」按鈕內（品牌、規格、包裝、產地、保存方式、標籤）。
3. **結果工具列**：顯示符合品項數、已套用條件、清除條件、卡片／清單切換；多選時採「全部符合」。
4. **預設清單列**：縮圖占位｜產品名稱＋品號｜規格／包裝｜產地／保存｜標籤｜`查看規格`＋`加入詢價籃`。不顯示價格、庫存、供貨承諾或交期。
5. **底部引導**：無結果時顯示「調整篩選條件」及「描述需求」；送出詢價後才由既有窗口依流程回覆。

## 取捨

- 產品數少（約 20 項內）：先用卡片較易理解；卡片的資料欄位仍要固定，避免每張資訊不同。
- 產品數多、採購者要比較規格：預設清單／表格式更合適；卡片可作為手機版呈現。
- 元家 PRD 已設定為「詢價」而不是線上交易，因此採「加入詢價籃」比每張商品各自跳到表單更能保留多品項採購脈絡。
